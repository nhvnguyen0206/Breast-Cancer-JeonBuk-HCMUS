## Protocol

Config `configs/vindr_cache_5090.yaml`: fresh ImageNet initialization, fold 0,
seed 42, 512px, batch 2, 4 loader workers, AdamW LR 5e-5, cosine over 50 epochs.
Run at least 20 epochs, at most 50, patience 10 on DEV four-class Macro-F1.
Patience counts non-improving epochs from the beginning, but stopping is gated
until epoch 20. Best checkpoint selection includes epochs before 20.

This does not resume the pilot's exhausted five-epoch learning-rate schedule.
Architecture, loss and FIT/DEV membership remain unchanged. CAL/OUTER remain
unused. Class-A limitations from the pilot still apply (FIT 2, DEV 0).

Cache root is `/slurmshared/Ngoc/datasets/VinDR_dicom_window16_cvatmask_v1`.
Remote `_images.jsonl` and `_input_provenance.json` hashes match the local
cache; source annotation and protocol hashes also match. Remote manifests
were regenerated using those exact sources and have the same class counts.
One remote FIT case was loaded successfully as `[4,3,512,512]` before submission.

W&B receives aggregate epoch metrics and aggregate confusion matrices only.
No medical images, case IDs, per-case CSVs or model weights are published.
The historical run is explicitly tagged `historical_import=true` and reports
its original training GPU as RTX 4090, not the upload host.
